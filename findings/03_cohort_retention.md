# Cohort Retention Analysis

## Executive Summary

This analysis evaluates monthly user retention across six acquisition cohorts from January to June 2024. Using a synthetic activity dataset containing 1,200 unique users and 3,016 activity records, the analysis measures how user engagement changes over time.

The results reveal a substantial decline in retention after the initial acquisition month, followed by a gradual decrease in subsequent months. The January 2024 cohort retained 26.6% of its original users by Month 6.

## Project Objective

Evaluate customer retention across monthly acquisition cohorts to:

- Measure monthly active users.
- Calculate months since acquisition.
- Construct a cohort retention matrix.
- Identify early user drop-off.
- Evaluate longer-term retention patterns.
